## Working rules

1. **Decision-oriented.** Each brief states problem → recommendation → open decisions → owner. No aspirational essays.
2. **Ideology sync.** Exec changes that alter product ideology must update [GDD](../GDD.md) and/or [non-goals](../non-goals.md) in the same change set.
3. **Wedge is the plan.** Detailed build stages stay in [wedge.md](../wedge.md). This portfolio funds and gates them; it does not replace them.
4. **Living docs.** Prefer short edits over new parallel memos.

## Deliberately deferred

- Full financial model / fundraising deck
- Enterprise sales motion
- Marketplace payments and ranking
- Sprint-level engineering plans (see wedge + repo)

## Owner

Default owner for open decisions: **founder** until roles split. Update the Owner line in each brief when that changes.

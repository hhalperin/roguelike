# 02 — ICP and jobs-to-be-done

**Status:** living  
**Owner:** founder  
**Decides:** Who we serve for Stages 2–5, trigger events, disqualifiers.

## Problem

Without a primary ICP, Stage 2 testing and GTM drift toward “anyone who codes with AI,” which dilutes the Ship-the-stub demo and feedback quality.

## Recommendation

### Primary ICP (Stages 2–5)

**Individual / power-user developers and small teams** already using **Cursor or Claude Code**, who feel:

- Agent-config rot (skills, rules, hooks accumulate into a junk drawer)
- Context thrash (every session re-explains the same project facts)
- Multi-task agent sprawl (too many threads, no single active room)

They want the agent to help ship **one thing at a time**, with a lean, intentional deck — not more config surface.

### Secondary ICP (later)

**Engineering managers** who want a **focus culture** (single-task discipline, visible climb progress) without buying another backlog tool. Do not optimize Stage 2 messaging for them.

### Trigger events

- New repo / greenfield spike where agent config is empty and painful to invent
- Existing `.claude` / Cursor rules feel stale or contradictory
- Team demo day: “show how you use AI” needs a crisp story
- Burnout from parallel agent chats and unfinished threads

### Job-to-be-done

> Help me ship **one thing at a time** with AI — without junk-drawer agent config — and make the session feel like a climb I can finish (or skip) cleanly.

Functional: deal a useful deck, clear rooms, skip junk.  
Emotional: feel in control of the path; AI advises, I choose.  
Social (secondary): “we run Spire on this repo” as a shared practice.

### Disqualifiers (do not chase yet)

| Disqualifier | Reason |
| :-- | :-- |
| Teams that want Spire to *own* the backlog / sprint board | Non-goal; see non-goals |
| Orgs requiring offline / air-gapped enterprise sales motion | Deferred; no enterprise funnel yet |
| Users who want fully autonomous multi-PR agents | Product is one room, player agency |
| Pure gamification buyers (badges without real repo work) | Save file must bridge to real work |

# 06 — Competitive and adjacent map

**Status:** living  
**Owner:** founder  
**Decides:** Buckets we sit near, differentiation, why we win / lose.

## Problem

Spire will be compared to coding agents, project tools, gamification apps, and learning platforms. We need a crisp map so messaging and roadmap stay in our lane.

## Recommendation

### Bucket table

| Bucket | Examples (illustrative) | Spire relationship |
| :-- | :-- | :-- |
| **Coding agents / IDEs** | Cursor, Claude Code, Copilot | Runtime we sit on; not competitors for “write code” |
| **Project / work trackers** | Jira, Linear, GitHub Projects | Adjacent for “what’s next”; we refuse backlog ownership |
| **Gamification / habit apps** | Streak/badge overlays on work | Compete for “discipline” attention; we use loop fun, not points-as-product |
| **Learning / course platforms** | Interactive coding courses | Compete for “guided path”; we guide *your* repo climb, not a sandbox curriculum |

### Differentiation (why Spire)

| Lever | Meaning |
| :-- | :-- |
| **Run structure** | Map → room → reward → campfire; sessions are climbs |
| **Lean deck** | Cards/relics/powers as intentional agent config; skip is healthy |
| **Real repo save** | `.spire/` + dealt primitives in the project |
| **One room** | Single active task; UI facets reinforce focus |

### 2×2 (conceptual)

```text
                 Structured session
                        ^
                        |
     Learning platforms |  **Spire**
                        |
   ---------------------+------------------> Real repo / production work
                        |
     Gamification apps  |  Agents / IDEs
                        |
                        v
                 Unstructured session
```

(Trackers sit off-axis: structured *backlogs*, not structured *play sessions*.)

### Why we win / why we lose

| Why we win | Why we lose |
| :-- | :-- |
| Fun loop + one-room habit beats junk-drawer config | If the loop isn’t fun, we’re a worse wiki |
| Save-file bridge makes progress real | Agents that ship multi-PR autonomy may feel “faster” to autopilot buyers |
| Content packs/climbs compound | Deep IDE-native features we don’t own can out-distribute us |
| Clear anti-positioning vs Jira+XP | Category confusion (“is this a game or a tool?”) if narrative is soft |

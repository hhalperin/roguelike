# 04 — Business model sketch

**Status:** living  
**Owner:** founder  
**Decides:** Who pays, for what, what stays free, what is deferred.

## Problem

We need a credible path from open wedge → revenue without building marketplace payments or enterprise sales before the loop is proven fun.

## Recommendation

### Near-term (through Stage 2 exit): free / open wedge

| Surface | Stance |
| :-- | :-- |
| Plugin / engine | Free enough to dogfood and recruit Stage 2 testers |
| Ship-the-stub / demo client | Free; exists to prove the loop |
| Authored starter content | Free with the demo |

**No paid conversion required** to exit Stage 2.

### Later paid surface (default after Stage 2 exit criteria)

| Who pays | For what |
| :-- | :-- |
| Individuals / small teams | **Packs** (discipline / stack content) |
| Individuals / small teams | **Climb templates** (vertical runs: ship stub, add endpoint, etc.) |
| Teams | **Seats** on the MCP client (shared climb chrome, team-oriented UX) |

**Engine stays open enough to dogfood** — paid value concentrates in content + client seats, not locking the detector/validator scripts behind a paywall.

### Explicitly deferred

Per [wedge.md](../wedge.md) Stage 2 exit and portfolio scope:

- Marketplace payments and ranking
- Enterprise procurement / SSO-led sales motion
- Full financial model / fundraising deck numbers

Do not staff payment infrastructure until Stage 2 exit criteria are met and Stage 4–6 content roadmap is funded ([moat](07-moat-content.md)).

### What stays free (principle)

- Ability to run a climb on a real repo with a lean deck
- Core deal / clear / skip / ascend loop
- Enough openness that contributors can author packs against public schemas ([content-schema](../content-schema.md))

## Open decisions

- [ ] Price anchor for first paid pack vs climb template (after Stage 2)
- [ ] Seat definition: per Cursor user vs per repo vs per org
- [ ] Whether engine license stays fully open-source or source-available
